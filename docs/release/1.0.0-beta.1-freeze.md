## Zaključavanje koda

- Tokom perioda ne dodajemo nove funkcije, jezike, modele tahografa, cene ni pravne tvrdnje bez zasebne provere.
- Dozvoljene su ispravke potvrđenih grešaka, bezbednosni popravci i preciziranja teksta; svaka ide kroz novu označenu verziju, probni Worker, testove i proveru na telefonu ako dira očitavanje.
- Verzija aplikacije i landinga mora biti vidljiva; čuvaju se GitHub commit i Cloudflare Worker version ID za svaku objavu i povratak.
- Po završetku deset dana pregledamo primljene rezultate. Stabilno izdanje `1.0.0` zahteva zasebnu odluku i kompletne podatke izdavača, kontakt i završenu proveru pravnih stranica.
